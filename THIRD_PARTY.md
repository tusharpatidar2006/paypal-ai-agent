## Verification

To verify dependency licenses:

```bash
# Python packages
pip-licenses --format=markdown --order=license

# Node packages
cd web && npx license-checker --summary
```

## Updates

Dependencies are pinned to specific versions for reproducibility. To update:

```bash
# Python
pip install --upgrade <package>
pip freeze > requirements.txt

# Node
cd web && npm update
```

**Security Note:** Always review security advisories before updating dependencies.
